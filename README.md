# Portfolio Source Code (`ChecksMc`)

A lightweight, static portfolio repository showcasing research papers and programming projects.

## How to View Locally

1. **Clone or Download**: Click the green `<> Code` button above and select **Download ZIP** (or clone via Git).
2. **Extract**: Unzip the downloaded folder to your computer.
3. **Open**: Double-click `index.html` to open the site in any standard web browser (Chrome, Firefox, Safari, Edge).

## Format & Hosting Notice

This portfolio is hosted directly as a public source repository rather than a deployed website. This approach was chosen to keep setup simple while navigating regulatory requirements (such as the German *Digitale-Dienste-Gesetz* / *Impressumspflicht*) as a minor, avoiding the need to publish personal contact details publicly online.

# Portfolio Quellcode (`ChecksMc`)

Ein einfaches, statisches Repository zur Präsentation von Forschungsarbeiten und Programmierprojekten.

## Lokale Vorschau

1. **Klonen oder Herunterladen**: Klicke oben auf den grünen Button `<> Code` und wähle **Download ZIP** (oder klone das Repository via Git).
2. **Entpacken**: Entpacke den heruntergeladenen Ordner auf deinem Computer.
3. **Öffnen**: Doppelklicke auf `index.html`, um die Seite in einem beliebigen Standard-Browser (Chrome, Firefox, Safari, Edge) zu öffnen.

## Format- und Hosting-Hinweis

Dieses Portfolio wird direkt als Quellcode-Repository statt als öffentlich gehostete Website bereitgestellt. Dies ermöglicht eine unkomplizierte Bereitstellung und berücksichtigt gleichzeitig die rechtlichen Rahmenbedingungen für Minderjährige in Deutschland (wie die Impressumspflicht nach dem Digitale-Dienste-Gesetz / DDG), ohne private Kontaktdaten im Internet veröffentlichen zu müssen.
